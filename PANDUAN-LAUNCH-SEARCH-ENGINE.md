## Pemeriksaan sebelum publikasi

- Jangan memasukkan `akses-guru.html` atau `kendali-editor.html` ke sitemap; keduanya sudah diberi `noindex`.
- Jangan mengganti canonical URL dengan alamat lokal atau alamat file komputer.
- Jangan meminta pengindeksan berulang kali untuk URL yang sama.
- Pantau laporan Pages/Indexing, Core Web Vitals, dan URL Inspection pada Search Console.

Konfigurasi teknis membantu mesin pencari menemukan dan memahami situs. Pengindeksan, posisi kata kunci, dan waktu kemunculan tetap menjadi keputusan masing-masing mesin pencari dan tidak dapat dijamin secara mutlak.
