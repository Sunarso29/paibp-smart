# Database Al Qur'an lokal PAIBP SMART SMP

Snapshot V78 ini disalin ke repository agar pembaca Al Qur'an berjalan di dalam aplikasi dan tidak mengalihkan pengguna ke website lain.

Sumber snapshot: rioastamal/quran-json. Repository sumber menyatakan bahwa sumber utama ayat dan terjemahannya berasal dari situs/aplikasi resmi Qur'an Kemenag.

Acuan resmi mutakhir: API Qur'an Kemenag LPMQ untuk Mushaf Standar Indonesia (rasm Usmani), yang memerlukan pendaftaran dan token dari LPMQ.

Validasi build: 114 surat dan 6.236 ayat.
