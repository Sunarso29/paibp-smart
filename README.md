# PAIBP SMART SMP — Versi 34 Light

Portal pembelajaran digital SMP Negeri 1 Susukan untuk PAIBP, 12 mapel lain, Koding dan Kecerdasan Artifisial, Fitur Islami, Game Edukasi, Spensus AI, dan Literasi Digital.

## Paket ringan

Versi ini terdiri atas **97 file** dengan ukuran sekitar **29 MB**. Seluruh 173 paket multimapel dirangkum dalam satu basis data terstruktur sehingga repository tidak lagi membawa ratusan salinan dokumen sumber yang membuat unggahan berat. Materi, ringkasan, LKPD, jawaban, cetak/PDF, dan pembuatan DOCX tetap tersedia melalui antarmuka web.

## Literasi Digital

Halaman `literasi-digital.html` menyediakan:

- katalog buku fiksi dan nonfiksi domain publik atau akses terbuka;
- pencarian langsung Open Library dan koleksi pilihan Project Gutenberg;
- tautan resmi menuju iPusnas, Indonesia OneSearch, Open Library, Project Gutenberg, dan OAPEN;
- filter judul, pengarang, bahasa, dan jenis buku;
- pratinjau metadata, baca daring, dan unduh melalui sumber resmi bila hak akses mengizinkan;
- statistik kunjungan, pencarian, pratinjau, baca, unduh, dan arah peminjaman yang disimpan secara lokal tanpa merekam identitas pengguna.

Katalog memakai model federasi. Situs tidak mengklaim menyimpan triliunan buku dan tidak menyalin buku berhak cipta ke repository.

## Fitur utama

- Ruang Murid: 30 paket PAIBP dan 173 paket multimapel kelas VII–IX.
- Mapel lain: Bahasa Indonesia, Bahasa Inggris, Matematika, IPA, IPS, Pendidikan Pancasila, Informatika, PJOK, BK, Prakarya, Seni Musik, Seni Tari, serta Koding dan Kecerdasan Artifisial.
- Materi Bab, Ringkasan, LKPD interaktif, latihan, penyimpanan jawaban, DOCX, dan cetak/PDF.
- Portal Guru terpisah dengan autentikasi identitas.
- Kendali Editor hanya bagi pemilik melalui sesi Portal Guru dan kata sandi editor.
- Al Qur'an, Hisnul Muslim, dzikir, jadwal sholat, kalender Hijriah, Bahasa Arab, khutbah Jum'at, dan tajwid praktis.
- Game edukasi, Spensus AI, informasi sekolah, galeri, statistik, dan komentar.
- PWA serta cache inti untuk penggunaan saat koneksi terbatas.

## Publikasi

Ekstrak ZIP, lalu unggah **isi foldernya**, bukan file ZIP, ke root repository. Karena paket hanya berisi 97 file, seluruh isi dapat dipilih dan diseret ke halaman **Add file → Upload files** dalam satu kali unggahan.
