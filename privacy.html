Kebijakan Privasi

Transparansi mengenai perlindungan data pada aplikasi PAIBP SMART SMP.

Berlaku mulai: 27 Juli 2026 · Pembaruan terakhir: 27 Juli 2026

Ringkasan: Versi 1.0 PAIBP SMART SMP dirancang tanpa login, tanpa iklan, tanpa ID iklan, dan tanpa pengumpulan atau pembagian data pribadi pengguna.

1. Tentang kebijakan ini

Kebijakan Privasi ini menjelaskan cara PAIBP Smart Studio, yang dikelola oleh Sunarso, S.Pd.I., Gr., menangani informasi ketika pengguna memakai aplikasi PAIBP SMART SMP dan mengakses situs resminya.

2. Data yang dikumpulkan

Aplikasi versi 1.0 tidak mengumpulkan data pribadi pengguna dan tidak mengirimkan data pengguna kepada developer maupun pihak ketiga. Aplikasi tidak meminta nama lengkap, alamat email, nomor telepon, alamat rumah, daftar kontak, pesan, foto pribadi, data keuangan, data kesehatan, atau lokasi presisi.

3. Data yang disimpan secara lokal

Pengaturan, progres belajar, bookmark, XP, lencana, dan preferensi tampilan dapat disimpan secara lokal pada perangkat pengguna. Data lokal ini tidak dikirimkan kepada developer dan dapat dihapus dengan menghapus data aplikasi atau mencopot pemasangan aplikasi.

4. Login dan akun

Versi 1.0 tidak mewajibkan login dan tidak menyediakan pembuatan akun. Oleh sebab itu, developer tidak menyimpan kredensial akun atau informasi identitas pengguna.

5. Iklan dan ID iklan

Versi 1.0 tidak menampilkan iklan, tidak menggunakan jaringan iklan, dan tidak menggunakan Advertising ID Android.

6. Lokasi dan jadwal sholat

Aplikasi tidak mengumpulkan lokasi presisi pengguna. Jadwal sholat untuk wilayah Susukan, Banjarnegara, menggunakan pengaturan wilayah tetap atau perhitungan lokal yang disediakan dalam aplikasi, bukan pelacakan lokasi pengguna.

7. Anak dan remaja

Aplikasi ditujukan terutama untuk murid SMP, guru, orang tua, dan pengguna umum. Karena tidak mengumpulkan data pribadi, aplikasi tidak meminta murid memberikan informasi identitas atau berkomunikasi dengan pengguna lain.

8. Keamanan

Developer menerapkan prinsip minimisasi data dengan tidak mengumpulkan data yang tidak diperlukan. Pengguna tetap disarankan menjaga keamanan perangkat, memperbarui sistem operasi, dan hanya memasang aplikasi dari Google Play.

9. Tautan eksternal

Aplikasi atau situs dapat menyediakan tautan menuju sumber pendidikan atau layanan resmi. Ketika pengguna membuka situs pihak ketiga di browser, kebijakan privasi pihak tersebut berlaku. PAIBP Smart Studio tidak mengendalikan praktik privasi situs pihak ketiga.

10. Perubahan fitur

Jika versi berikutnya menambahkan login, analitik, sinkronisasi awan, AI, iklan, pembelian, atau pengumpulan data lain, Kebijakan Privasi dan deklarasi Keamanan Data di Google Play akan diperbarui sebelum fitur tersebut dirilis.

11. Hak pengguna

Karena versi 1.0 tidak menyimpan data pribadi pada server developer, tidak terdapat akun atau data server yang perlu diminta untuk dihapus. Pengguna dapat menghapus data lokal melalui pengaturan perangkat atau dengan mencopot pemasangan aplikasi.

12. Situs web

Situs resmi ini tidak menggunakan akun pengguna, formulir pengumpulan data, cookie pelacakan, iklan, atau analitik pihak ketiga. Server hosting dapat memproses log teknis dasar sesuai kebijakan penyedia hosting.

13. Perubahan kebijakan

Kebijakan ini dapat diperbarui untuk menyesuaikan perubahan aplikasi, hukum, atau kebijakan Google Play. Tanggal pembaruan akan dicantumkan pada bagian atas halaman ini.

14. Kontak

Pertanyaan mengenai privasi dapat disampaikan melalui halaman Kontak atau email developer yang tercantum pada listing Google Play.

Catatan penting: Kebijakan ini disusun untuk versi 1.0 yang tidak mengumpulkan data. Deklarasi wajib diperbarui apabila perilaku aplikasi berubah.
